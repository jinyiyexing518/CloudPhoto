# CloudPhoto 用户手册

## 1. 访问方式

CloudPhoto 支持两种使用方式：

1. 网站方式：直接在浏览器中打开
2. App 方式：通过浏览器安装到主屏幕/桌面后使用

两种方式使用同一账号和同一数据。

### 1.1 登录与注册

登录和注册继续使用浏览器原生表单校验，因此无效字段会自动获得焦点并显示原生提示气泡：

1. 登录用户名、登录密码、注册用户名、昵称和邮箱为空时，会显示对应的中文必填提示
2. 注册邮箱格式不正确时，会显示“请输入有效的邮箱地址”
3. 修改字段后，旧提示会立即清除，不会阻止后来输入的合法值
4. 密码长度、两次密码不一致和提交 API 错误仍显示在页面内；无效表单不会发送登录或注册请求

在 320px、390px 和 500px 宽度下，认证页面不会横向滚动。注册表单较长时由整个页面正常纵向滚动，不会在表单内部再出现一层双轴滚动区。页签、输入框、密码显示按钮、提交按钮和安装入口均提供至少 44×44px 的点击 / 触控区域，并与页面正文使用一致的系统字体。

登录后顶部提供时间线、文件夹、重要片段、记忆地图、时光胶囊和自动故事六个工作区页签；当你进入“时间线”或“重要片段”时，可以打开一个从右侧滑入的全高侧边栏来承载筛选和洞察信息。这个侧边栏会占据大约 80%–90% 的横向宽度，剩余区域保持变暗，让你明确感知它是“从侧边弹出的工具面板”。

侧边栏里会提供：

1. 时间线筛选
2. 快捷整理入口（最近上传 / 缺少主题 / 未分类）
3. 重要片段概览
4. 分享与同步相关入口

你也可以手动关闭侧边栏；关闭后可通过页面右下角的胶囊悬浮组件重新打开。现在这个入口已经升级成“主胶囊 + 次级胶囊”组合，能更直接地区分主操作和辅助入口。

为了避免入口不明显，右下角的胶囊悬浮组件和侧边栏内的关键操作卡片都已做成更大、更醒目的样式，并带有更明确的侧滑动画。侧边栏内容本身也支持独立滚动，因此可以直接滚动到底部看到全部内容。

键盘打开侧边栏后，焦点会进入关闭按钮并留在面板内循环；按 Escape 或点击暗色背景可关闭并回到原悬浮入口。侧边栏关闭时不会进入 Tab 顺序或读屏内容；从侧栏打开设置等弹窗后，关闭弹窗会回到原侧栏操作。

顶部额外会显示一条更轻量的“聚焦导航条”，用于快速确认：

1. 当前所在空间（个人空间 / 群组空间）
2. 当前总照片数
3. 已使用文件夹数
4. 已收藏照片数
5. 已标注主题数
6. 当前是“网页模式”还是“App 模式”

顶部六个工作区页签现在也做了不换行优化；在较窄宽度下会优先保持整行可读，而不是被挤压到难看的换行状态。
顶部导航现在还会给出更明确的“可左右滑动”视觉提示，避免用户误以为最右侧内容没有渲染出来。

右上角“设置”也做了样式升级：

1. 每个页签顶部会显示更清晰的说明头图
2. 头图图标已改成更克制的分场景配色，不再全部使用偏重的蓝色渐变
2. 信息内容按卡片分组，不再是一整串平铺字段
3. 个人信息、安全、应用、诊断的阅读层次更明确

其中有内容规模的页签会直接显示数量：

1. 时间线：当前可见照片数
2. 文件夹：已使用文件夹数
3. 重要片段：当前重点照片数
4. 记忆地图：当前含有效 GPS 的照片数

使用键盘聚焦任一工作区页签后，按 ← / → 会循环切换并立即打开相邻视图，Home / End 可跳到首个 / 末个视图，Enter / Space 保留按钮原生操作。即使 Header 或页签已随滚动隐藏，Tab / Shift+Tab 或这些导航键到达时也会立即恢复可见；焦点仍在导航、菜单/侧边栏打开或弹窗活跃期间不会再次隐藏。若上传、下载、批量操作、回收站、维护、文件夹重命名或弹窗边界正在阻止切换，当前页签和焦点都会保持不变；窄屏会自动把新页签滚动到可见位置。

按 Tab 第一次进入已登录页面时，会出现“跳到主要内容”入口；激活后可跳过顶部导航和六个页签，直接聚焦当前视图。切换页签后目标会同步更新；侧边栏或模态弹窗打开时不会把焦点送到后台内容。

进入对应页签后，右侧侧边栏中可看到：

1. 最近上传：查看近 7 天上传数量，并可一键跳到时间线中的目标照片位置
2. 分享表现：查看当前有效分享链接数、累计分享浏览量，并可直接进入分享管理对应区域
3. 同步健康：查看 moments 浏览同步状态，并可直接打开诊断页对应内容区

同一个侧边栏中还包含三块更偏“产品运营”的辅助区：

1. 最近活动流：集中显示最近上传、最近创建的分享和最近同步状态变化，并支持直接定位到对应内容
2. 内容整理助手：自动提示“缺少主题”和“未分类”的照片数量，并可一键跳转处理到目标照片区域
3. 分享预警卡：提示 48 小时内即将过期的分享链接数量，并可直接进入分享管理的对应链接区域

## 2. 安装为 App

统一入口（推荐）：

1. 登录后点击右上角“设置”
2. 打开“📱 应用”页签
3. 点击“立即安装 App”或“查看安装指引”

说明：

1. 是否支持“一键安装”取决于当前浏览器
2. 不支持时，请按下方设备指引手动安装

### 2.1 Android

1. 用 Chrome 或 Edge 打开 CloudPhoto
2. 点击地址栏安装图标，或浏览器菜单中的“安装应用”
3. 安装后，从桌面图标打开

### 2.2 iPhone / iPad

1. 使用 Safari 打开 CloudPhoto
2. 点击“分享”按钮
3. 选择“添加到主屏幕”
4. 回到主屏幕后，从图标打开

### 2.3 电脑（Windows / macOS）

1. 用 Chrome 或 Edge 打开 CloudPhoto
2. 点击地址栏安装图标，或浏览器菜单中的“安装应用”
3. 安装后可在桌面/开始菜单中启动

---

## 3. 上传照片与视频

1. 切换到"文件夹"视图
2. 进入目标文件夹
3. 点击"添加原图"并选择文件（支持同时选择图片和视频）

支持的格式：

- **图片**：JPEG / PNG / GIF / WebP / HEIC / HEIF / BMP / TIFF（单文件最大 20 MB）
- **视频**：MP4 / MOV / WebM / AVI / MPEG / 3GPP（单文件最大 200 MB）

说明：

1. 默认上传原文件，不会压缩
2. 支持批量上传（图片与视频可混选）
3. 上传进度条显示**实际传输字节数**（X.X / Y.Y MB），视频上传时进度条会平滑更新
4. 视频缩略图自动定位到约 10% 时长处的帧，以**居中裁剪**方式填满缩略图格，不拉伸、不显示边角
5. 视频卡片右下角显示 ▶ 标识，在详情页中可直接播放
6. 上传过程中请不要刷新页面或关闭窗口

---

## 4. 下载照片

1. 点击照片打开详情
2. 选择“下载原图”

说明：

1. 默认下载原图
2. 下载过程中请不要刷新页面或关闭窗口

---

## 5. 创建分享链接

1. 点击照片/视频打开详情
2. 点击操作栏中的 **🔗 分享** 按钮（展开分享面板）
3. 选择有效期（1 小时 / 24 小时 / 3 天 / 7 天）
4. 点击"复制链接"

说明：

1. 每次点击"🔗 分享"会展开/折叠分享面板
2. 分享面板中有 🔒 隐私提示，请在创建前确认照片不含身份证、银行卡等敏感信息
3. 默认是一键自动复制；如果浏览器限制剪贴板接口，系统会自动尝试兼容方式
4. 链接过期后自动失效
5. 如果链接已创建，但浏览器因配额、隐私模式或存储权限无法保存近期记录，链接仍会正常显示/复制，并提示“未保存到最近记录”；系统不会再次创建一条新链接
6. 托管分享会在每次打开时重新核对创建时记录的个人/群组空间，不能借失效或被篡改的路径访问其他空间

### 5.1 分享当前文件夹

1. 切换到“文件夹”视图并进入目标文件夹
2. 点击“分享当前文件夹”
3. 在弹出的分享面板里选择有效期（1 小时 / 24 小时 / 3 天 / 7 天）
4. 点击“确认分享”

说明：

1. 有效期不再显示在工具栏左侧，而是在弹窗中选择
2. 这样可以让文件夹工具栏保持紧凑，同时让分享操作更清晰
3. 公开页面只包含该文件夹里的普通照片/视频；内部语音文件和缩略图派生文件不会被列出或签发访问地址

### 5.2 管理最近分享链接（设置内）

1. 点击右上角“设置”
2. 打开“📱 应用”页签
3. 在“云端分享链接（可维护）”中可执行：复制、打开、延长、立即失效
4. 可通过“状态筛选 + 文件名搜索”快速定位链接
5. 当前浏览器保存的近期公开链接只属于当前账号与角色；注销、会话失效、切号或角色变化会清理本地记录，下一账号不会看到上一账号的链接。云端已创建的托管分享不会因此被删除

说明：

1. 云端分享链接支持统计信息：创建时间、到期时间、浏览量、最近访问时间
2. “立即失效”会让链接马上不可用
3. “延长”会按你选择的默认时长继续延长（1 小时 / 24 小时 / 3 天 / 7 天 / 30 天）
4. 系统会自动把“已到期但曾显示有效”的链接纠正为“已过期”状态
5. 如果多人同时操作同一条分享链接，系统会提示“资源已被他人修改，请刷新后重试”

### 5.3 本地分享记录（当前浏览器）

1. 仍可在“本地分享记录”中查看最近复制过的链接
2. 支持复制、打开、删除、清空

说明：

1. 本地记录仅保存在当前浏览器，不是跨设备同步
2. 链接过期后会自动从列表中清理
3. 浏览器存储不可用时，读取会安全显示为空；删除或清空会明确提示失败，不会让设置页崩溃或误报成功

### 5.4 详情里文件名很长怎么办

1. 详情面板会自动省略超长文件名（显示为 ...）
2. “重命名”等按钮会保持可见，不会被文件名遮挡

说明：

1. 你可以把鼠标悬停在文件名上查看完整名称（桌面端）
2. 如需彻底变短，建议直接使用“重命名”

## 6. 语音备注

你可以为任何照片或视频录制一段语音备注。录音会单独存储，不影响原始文件。

**录制语音备注：**

1. 点击照片/视频打开详情
2. 点击操作栏中的 **🎤 语音** 按钮（展开语音面板）
3. 点击"🎤 开始录音"（首次使用时浏览器会请求麦克风权限）
4. 录音完成后点击"⏹ 停止"，系统会自动上传语音备注
5. 上传完成后即可在面板中点击播放器收听

**播放和删除：**

1. 已有语音备注的照片，操作栏按钮会显示为 **🎤 备注✓**
2. 打开语音面板后可直接使用 `<audio>` 播放器播放
3. 点击"🗑 删除备注"可移除语音备注（不影响照片本身）

说明：

1. 语音文件格式：Chrome/Android 使用 `webm`，Safari/iOS 使用 `mp4`
2. 语音备注单文件最大 20 MB（约 20 分钟）
3. 语音文件存储在内部 `_voice` 文件夹中，不会出现在相册列表里

## 7. 回收站

1. 删除照片后会进入回收站（软删除）
2. 可在回收站中恢复或彻底删除
3. 恢复后会回到原文件夹
4. **清空回收站**时，对话框内会显示实时进度条（已删除 / 总数 + 百分比），完成后弹出结果提示

说明：

1. 手机端会在底部显示固定操作区，方便单手点击"恢复选中/彻底删除选中"
2. 清空或批量删除过程中，相关按钮暂时禁用，防止重复触发

---

## 8. 批量删除进度

在时间线或文件夹内进入批量选择模式后执行"删除选中"：

1. 页面顶部出现 🗑️ 删除进度条，显示"删除中 X/总数"和百分比
2. 所有照片依次删除，完成后进度条消失并弹出结果提示
3. 删除过程中可正常浏览页面，无需等待

---

## 9. 最近更新提示（What's New）

每次进入应用时，如果过去 3 天内有新功能上线，右下角会弹出"🎉 最近更新"卡片：

1. 卡片列出每项更新的图标、名称和一句话说明
2. 底部紫色进度条倒计时 10 秒后自动消失（有淡出动画）
3. 右上角 ✕ 可立即关闭
4. 已关闭或自动消失后，同一批更新不会再次弹出

---

## 10. 时间线智能浏览

1. “历史回忆”会展示历年同月同日拍摄的照片
2. "重要片段"已独立为顶部新页签（⭐ 重要片段）；按互动热度排序后**只展示前 20 张**最佳照片
3. 时间线默认按「📷 拍摄时间」排序；可切换为「☁ 上传时间」，无拍摄时间时自动回退到上传时间
4. 时间线支持"加载更多"，默认先显示最新一批
5. 如果筛选后没有结果，页面会直接提供"清空筛选"或"去文件夹视图"的恢复按钮
6. 支持两种整理向筛选："无主题"用于集中补充主题描述；"未分类"用于集中整理仍在根目录的照片
7. 快捷筛选行最右侧有一个排序切换按钮："↓ 最新"表示时间倒序（默认），"↑ 最早"表示时间正序；不影响其他筛选条件
8. 当任一筛选启用时，时间线页签标签上会出现一个橙色小点提醒
9. 切换群组/个人空间时，所有已展开的筛选条件会自动清空，避免跨空间搜索残留

### 10.1 排序方式切换（拍摄时间 / 上传时间）

时间线工具栏快捷 chip 行新增两个排序按钮：

- **📷 拍摄时间**（默认）— 按照片的实际拍摄时间分组排序；如果照片没有 EXIF 拍摄时间，自动回退到上传时间
- **☁ 上传时间** — 按照片上传到云端的时间分组排序

说明：

1. 切换排序方式不影响其他筛选条件
2. 历史照片若缺少拍摄时间，可用「历史照片回填」功能从 EXIF 补全（见设置 → 📱 应用）

---

### 10.2 重要片段里的"推荐值"和"浏览"怎么算

1. 推荐值由三部分组成：收藏加权 + 主题加权 + 时间新近度
2. 浏览来自“你在重要片段中打开详情/左右切换”的累计记录
3. 当服务端 `moments` 可用时，浏览记录跨设备同步；若服务端暂时不可用，当前设备会先本地保存，刷新后不清零，但跨设备不会立刻一致
4. 排序默认使用“互动热度”，会综合推荐值、浏览量、分享量、最近查看加成

说明：

1. 推荐值更偏向“内容质量”（收藏/主题/时间）
2. 互动热度更偏向“真实关注度”（谁在看、看了多少次）

### 10.3 重要片段详情页现在看什么

重要片段详情页优先显示：

1. 推荐值
2. 互动热度
3. 查看次数
4. 分享量
5. 最近查看
6. 常看用户
7. 浏览高峰日

说明：

1. 这些是“重要片段视角”指标
2. 时间线视角的上传/修改元数据仍在非重要片段模式展示

### 10.4 重要片段筛选项（按展示指标）

你可以按以下方式筛选：

1. 热度（高 / 中 / 低）
2. 推荐值（高推荐值 / 已收藏优先 / 近 30 天）
3. 浏览量（高频浏览 / 已有浏览 / 暂无浏览）
4. 分享量（已有分享 / 高分享量 / 暂无分享）

你也可以按以下方式排序：

1. 按互动热度排序
2. 按浏览量排序
3. 按最近查看排序
4. 按分享量排序
5. 按推荐值排序

如果当前筛选组合没有命中照片：

1. 页面会显示明确的空结果提示
2. 你可以一键点击“重置片段筛选”恢复默认推荐视图

### 7.4 历史照片位置回填（并补全拍摄时间）

如果早期上传的照片缺少 GPS、坐标无效或只保存了纬度 / 经度一侧，可以使用一键回填从 EXIF 恢复位置；同一候选照片缺少拍摄时间时也会顺带补全。仅缺少拍摄时间但 GPS 已合法的照片不会单独触发原图扫描。

1. 点击右上角「设置」
2. 打开「📱 应用」页签
3. 找到「历史照片回填」卡片并点击「开始回填」；系统会先执行不读取原图的候选估算，再显示预计最大读取量供你确认
4. 确认后系统会分批处理缺少或包含无效 GPS 的非删除照片，从 EXIF 恢复拍摄时间和合法坐标
5. 完成后会分别显示候选、恢复、真实缺失、无效清理、预算跳过、读取字节和失败统计

说明：

1. 已有完整合法 GPS 坐标的照片不会下载原图或被覆盖；NaN、越界和只有纬度 / 经度一侧的旧坐标会作为恢复候选
2. 只有照片本身包含 EXIF 信息时才能成功提取
3. 回填完成后，时间线按「📷 拍摄时间」排序时会立即体现更新后的分组
4. 大型图库会按安全游标、文件读取上限、每页 8 MiB 预算和请求截止时间分批处理；预算跳过或读取不完整的照片不会被误清理，下次任务仍可重试

### 7.5 批量修改拍摄时间

在时间线或文件夹内进入批量选择模式后，可以为多张照片一次性设置拍摄时间：

1. 点击「批量选择」并勾选目标照片
2. 点击工具栏中的「修改时间 (N)」按钮
3. 在弹出的日期时间选择器中选择目标拍摄时间
4. 点击「应用」，所有选中照片的拍摄时间将统一更新

说明：

1. 时间以你设备的本地时区为准，不会发生时区偏移
2. 修改后时间线会按新的拍摄时间重新分组

---

### 7.6 批量修改 GPS 位置

在批量选择模式下，可以为多张照片一次性设置地理坐标：

1. 点击「批量选择」并勾选目标照片
2. 点击工具栏中的「修改位置 (N)」按钮
3. 输入纬度（-90 ~ 90）和经度（-180 ~ 180）
4. 点击「应用」，所有选中照片的 GPS 坐标将统一更新

说明：

1. 更新后记忆地图中这些照片会出现在新的坐标位置
2. 可以通过地图应用查找目标地点的坐标后再填入

### 7.8 诊断页看什么

1. 打开右上角“设置”
2. 进入“🩺 诊断”页签

这里会显示：

1. 前端版本
2. 构建时间
3. 当前运行模式（网页 / 已安装 App）
4. Service Worker 注册数
5. 本地重要片段浏览记录条数

4. 本地统计和诊断只属于当前账号、角色及个人 / 群组空间；注销、会话失效、切号或角色变化会通过浏览器标准存储键接口立即清理这些私有数据，但不会删除应用壳和已缓存的功能代码

## 7.5 历史上的今天（On This Day）

每次进入"时间线"标签，系统会自动检测往年同月同日是否有照片。若有，时间线顶部会出现一张「历史上的今天」卡片：

1. 卡片按年份分组，显示当年对应日期的照片缩略图
2. 每张缩略图右下角显示「X年前」标签
3. 超过 6 张时，点击「+N」可展开查看全部；点击任意缩略图跳转到时间线中对应照片

## 7.6 记忆地图（Memory Map）

进入「🗺️ 记忆地图」标签查看所有含 GPS 位置的照片在世界地图上的分布：

1. **自动 GPS 提取**：上传照片时，客户端从图片 EXIF 中自动读取 GPS 坐标，写入服务端 blob 元数据，无需手动操作
2. **地图标注**：有 GPS 信息的照片以圆形缩略图图标标注在 OpenStreetMap 地图上
3. **详情面板**：点击任意图标，底部弹出详情面板，显示照片预览、文件名、坐标及拍摄日期；点击「在时间线中查看」可跳转到对应照片
4. 标签页按钮上显示含位置信息的照片数量
5. 键盘可用 Tab 聚焦地图标记，Enter / Space 打开详情；标记视觉圆点保持原位置，但实际点击 / 触控区域至少 44×44
6. 位置搜索结果是至少 44px 的原生按钮，可用方向键移动、Enter 选择、Escape 关闭并回到原入口；清空、关闭或切换空间会取消旧搜索，迟到结果不会覆盖当前输入。编辑 GPS 时可用 Tab / Shift+Tab、Escape，保存期间不能提前关闭，失败会保留输入。纬度 / 经度必须是完整有限数值并处于 ±90 / ±180 范围
7. 新上传的 JPEG / HEIC 即使浏览器未提供标准 MIME，也会尝试从 EXIF 恢复合法 GPS，并在上传后立即刷新详情与地图；若只有地址服务暂时失败，会显示“地址暂不可用”，不会误报成没有 GPS

## 7.7 时光胶囊（Time Capsule）

进入「💌 时光胶囊」标签管理你的封存照片：

1. **新建胶囊**：点击「✦ 新建胶囊」，输入名称、选择照片（可按文件夹筛选）、设定解锁日期后确认创建
2. **增量选择**：照片区先显示 18 张，滚动到底部每次追加 12 张；同一空间内切换来源或重开窗口会回到首批，但已经勾选的照片和计数不会丢失。切换个人 / 群组空间后会为新空间重新开始未提交选择
3. **媒体封面**：视频只显示静态封面或占位；音频显示带图标和“音频”标记的本地占位。浏览选择列表不会加载原视频或音频
4. **锁定状态**：到期前胶囊显示锁图标和倒计时「还有 X 天解锁」
5. **解锁状态**：到期后胶囊自动变为「已解锁」，点击「打开」可浏览全部封存照片
6. 点击任意封存照片可跳转到时间线对应位置
7. 数据按账号和个人 / 群组空间分别保存在浏览器本地（`localStorage`）；旧版本记录只迁移到个人空间，切换空间不会看到其他空间的胶囊
8. 损坏、非法、越界或包含 URL / SAS 参数的记录会被安全忽略；浏览器拒绝读取、配额不足或写入失败时页面会明确提示，不会把未保存的创建 / 删除显示成成功

## 7.8 自动故事（Auto Story）

进入「🎬 自动故事」标签创建并播放幻灯片故事：

1. **选择来源**：从下拉菜单中选择全部照片或某个文件夹；故事只纳入图片和已有静态派生封面的视频，音频、未知类型和无封面视频不进入预览、计数或播放器
2. **选择效果**：淡入淡出 / 滑动 / 缩放
3. **选择间隔**：2 / 3 / 4 / 5 / 8 / 10 秒
4. 点击「▶ 开始播放」进入全屏幻灯片模式
5. **播放控制**：顶部只有一个原生进度滑杆，可点击或拖动跳转，并会与自动播放、上一张 / 下一张和当前计数保持同步；底部按钮可暂停 / 恢复、上一张、下一张、退出
6. **键盘控制**：聚焦进度滑杆时可用方向键微调、Home / End 跳到首尾；其他位置用 ← / → 切换上下张，Esc 退出全屏
7. 背景会自动使用当前照片的模糊大图，增强沉浸感

## 7.9 照片卡片快捷操作菜单

在时间线、重要片段或文件夹中，可以不先打开详情就操作照片：

## 9. 常见问题

### 9.1 看不到“安装应用”按钮

1. 请先在“设置 -> 📱 应用”中查看是否支持一键安装
2. iOS 不会显示统一安装弹窗，请用 Safari 的“添加到主屏幕”
3. 站点必须是 HTTPS
4. 若曾拒绝安装，浏览器会有冷却期

### 9.2 分享链接创建失败或打不开

1. 请先确认当前照片可正常预览
2. 若提示权限问题，请联系管理员检查 Azure 存储权限
3. 若链接复制成功但外部打不开，通常是存储网络策略限制了公网访问

### 9.3 上传或下载被中断

1. 常见原因是刷新页面、切换页面或关闭应用
2. 传输期间请保持当前页面

### 9.4 手机返回键为什么会直接退出

1. 在“文件夹”内浏览时，返回键会优先回到上一级文件夹
2. 回到文件夹根目录后，再按返回才可能退出应用

说明：

1. 这是为了避免在多层文件夹中误触返回导致直接退出

### 9.5 进入页面后反复刷新怎么办

1. 开发环境（本地 yarn dev\uff09已关闭 PWA Service Worker，默认不会出现 SW 引起的循环刷新
2. 普通网页版与已安装 App 都会自动更新 SW；首次只预缓存应用壳，图库等功能代码用到后才缓存
3. 已安装 App（PWA）会复用已访问功能的缓存与离线应用壳，但内容数据仍以在线服务为准
4. 若网页版看起来还是旧版本，可先去“设置 -> 🩺 诊断”确认前端版本与构建时间

### 9.6 提示“资源已被他人修改，请刷新后重试”是什么意思

1. 这表示你和其他人几乎同时修改了同一张照片或同一条分享链接
2. 为防止数据被互相覆盖，系统会拒绝冲突写入并提示重试
3. 刷新列表后重新操作即可

### 9.7 为什么页签上会显示数字

1. 这是为了帮助你更快判断当前每个视图里大概有什么内容
2. 时间线数字表示当前可见照片数
3. 文件夹数字表示当前已使用的文件夹数
4. 重要片段数字表示当前重点照片数
5. 这可以减少在多个页面之间来回切换试错
